# O Próximo Cliente

Material da agência O Próximo Cliente (@oproximocliente). Leia antes de criar criativos, páginas, roteiros de pré-vendas ou propostas comerciais da agência.

- [ESTRATEGIA.md](ESTRATEGIA.md): posicionamento, persona, planos (Largada, Demanda, Agenda, Escala), Método OPC, provas, identidade visual, funil e campanha de teste.
- [TEXTOS-BASE.md](TEXTOS-BASE.md): os 10 textos originais do fundador, base dos ganchos e roteiros.
- [criativos/](criativos/): criativos animados em HTML (9:16, com efeitos sonoros). `01-lead-esfria-5-minutos.html` é o primeiro teste (texto 01, gancho B).

O nome da marca é sempre "O Próximo Cliente", com o artigo.
