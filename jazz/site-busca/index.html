Este JSON é o retorno de fn_interpretar_busca() — é dele que saem os chips acima.

Por que os chips importam. Eles devolvem ao visitante o controle que o combo dava, sem cobrar o clique adiantado — e respondem “por que este imóvel apareceu?”. Clique no ✕ de qualquer um para soltar aquele filtro.

Contagem é piso, não igualdade. “3 quartos” traz 3 e 4 dormitórios: ninguém recusa um quarto extra dentro do orçamento.

Número sem escala é milhar. “apartamento de 700” significa 700 mil.
