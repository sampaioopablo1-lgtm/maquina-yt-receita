[ ETAPA 1 · CONEXÃO ]
O QUE O SETUP INSTALA NA SUA MÁQUINA

Não é curso, não é PDF. É um setup que você roda uma vez e deixa a sua conta de anúncio acessível ao Claude Code e ao Codex.

MCP oficial da Meta

Conexão OAuth entre o Claude Code ou o Codex e sua conta de anúncio — com caminho alternativo (System User Token) para contas que ainda não têm o MCP liberado.

CAPI + API de Conversões

agente-trafego-pago

O orquestrador: um menu que entende o que você pediu e roteia para a skill certa.

meta-campaign-launcher

Cria campanha + conjunto + anúncio a partir de uma frase em português — sempre em PAUSED, pra você revisar antes.

meta-metrics-fetcher

Puxa insights da API e alimenta o dashboard sem você abrir nada.

meta-performance-analyzer

Aplica os seus limiares e devolve veredito SCALE / KILL / KEEP por entidade.

meta-budget-optimizer

Propõe realocação de verba entre campanhas com base no que está performando.

meta-creative-brief

Gera briefing de criativo por ângulo — hook de copy, hook visual e CTA.

Google Ads

Criativos com IA
